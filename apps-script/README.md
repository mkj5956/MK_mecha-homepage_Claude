# 의뢰 접수 서버 설치 (Google Apps Script · 무료)

고객 의뢰를 **구글 시트**에 저장하고, 첨부파일은 **구글 드라이브**에, 새 의뢰는 **이메일**로 알려줍니다.

## 1. 스크립트 만들기
1. https://script.google.com → **새 프로젝트**
2. 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs` 전체를 붙여넣기 → 저장
3. 왼쪽 ⚙ **프로젝트 설정** → **스크립트 속성** → `ADMIN_EMAIL` = 알림 받을 이메일 추가

## 2. 초기화
1. 편집기 상단 함수 선택에서 `setup` → **실행** → 권한 승인 (시트·드라이브·메일)
2. **실행 로그**에 나온 `ADMIN_TOKEN` 값을 복사해 둡니다 (관리자 페이지에 입력).

## 3. 웹앱 배포
1. **배포 → 새 배포 → 유형: 웹 앱**
2. 실행 사용자: **나** / 액세스 권한: **모든 사용자**
3. 배포 → 나오는 URL(`https://script.google.com/macros/s/.../exec`) 복사

## 4. 홈페이지에 연결
- `js/config.js` → `appsScriptUrl: '복사한 URL'` → 커밋 (고객 접수용)
- 관리자 페이지 → 설정 → **Apps Script 웹앱 URL**, **관리자 토큰** 입력 → 저장 → **연결 테스트**

## 참고
- `Code.gs` 를 수정하면 **배포 → 배포 관리 → 편집 → 새 버전**으로 다시 배포해야 반영됩니다.
- 무료 한도: 메일 하루 100통(일반 계정), 실행 6분/회 — 소규모 설계사무소 운영에 충분합니다.
- 고객 확인 메일이 필요 없으면 `notify()` 의 두 번째 `MailApp.sendEmail` 줄을 삭제하세요.
- 고객 목록 조회·수정은 `ADMIN_TOKEN` 이 있어야만 가능합니다. 토큰이 노출되면 스크립트 속성에서 바꾸세요.
