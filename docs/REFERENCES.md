# 설계 기준 · 참고 자료

## 적용된 설계 기준 (js/kb.js, drawing.js)
| 항목 | 기준 | 적용 위치 |
|---|---|---|
| 투상법 | KS B 0001 (제도 통칙) 3각법 | 도면 배치 (평면도 위, 우측면도 오른쪽) |
| 일반공차 | KS B ISO 2768-1 (f/m/c) | 도면 주기, `tolOf()` |
| 볼트 관통 구멍 | KS B ISO 273 (중급) | 구멍 콜아웃, 주기 |
| 표면거칠기 | KS B ISO 1302 (Ra 표기) | 주기 "지시 없는 면 Ra 6.3" |
| 재질 | KS D 3503(SS400), 3752(S45C), 6701(AL), 3698(SUS304) | 물성·단가·표면처리 |
| 프레스 안전 | 산업안전보건기준에 관한 규칙 제103조 | 프레스 검증 항목 |
| 볼스크류 위험속도 | n = f·10⁷·d_r / L² (고정-지지 f=15.1) | 리프트 검증 |
| 보 처짐 | δ = 5wL⁴ / 384EI (등분포·단순지지) | 프레임/컨베이어 검증 |
| 컨베이어 동력 | P = μ·m·g·v / η | 모터 선정 |
| 인덱스 토크 | T = J·α, α = 4θ/t² (삼각 프로파일) | 로터리 검증 |

## 활용한 오픈소스
- three.js (MIT) — 3D 렌더링 / pdf.js (Apache-2.0) — PDF 텍스트·렌더 / tesseract.js (Apache-2.0) — OCR / JSZip (MIT)

## 기능 확장 시 참고할 오픈소스 (GitHub)
- CadQuery, build123d — 파이썬 파라메트릭 CAD (STEP 출력이 필요할 때)
- FreeCAD — TechDraw 워크벤치(정식 2D 도면), FEM
- OpenSCAD — 스크립트 CAD
- ezdxf — DXF 읽기/쓰기 (파이썬)
- OpenCascade.js — 브라우저용 B-Rep 커널 (CSG·STEP을 웹에서)
- Rapier / cannon-es — 물리 엔진 (정밀 충돌·동역학)
