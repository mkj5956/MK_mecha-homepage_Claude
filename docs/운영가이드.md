# 운영 가이드 — 구독(Claude/ChatGPT)만으로 운영하기

## 하루 업무 루틴
1. 새 의뢰 알림 메일 수신 → 관리자 → **의뢰함 → 서버에서 새 의뢰 가져오기**
2. **프로젝트로 전환** → 고객이 본 3D 설계안·답변·선택 견적이 그대로 넘어옵니다.

## 프로젝트 단계별

### ① 분석·질문
- 자동 분석 결과(읽어낸 치수, 제안, 확인 질문)를 확인 → **질문 메일 보내기**.
- 정밀 분석이 필요하면 **AI 도우미 → ① 의뢰 정밀 분석** (아래 "AI 도우미 사용법").

### ② 견적
- 저가/표준/고가 비교표, 부품별 원가. 수량 변경 시 학습효과 할인 자동 반영.
- **견적 확정 → 견적서 출력(PDF 저장)** → **고객에게 견적 메일**.
- 단가가 시장과 다르면: 설정 → 보정 계수 / `js/kb.js` 단가 수정.

### ③ 3D 설계·검증
- 슬라이더로 치수·사양 수정 → 즉시 재설계 + **작동 애니메이션** + **동적 간섭 검사**(1주기 120단계) + **공학 검토**(모터 동력/토크, 처짐, 위험속도, 실린더 내경 등).
- 빨간 부품 = 간섭. "보기"를 누르면 간섭 시점으로 이동.
- **공유 링크 생성 → 고객에게 메일**: 고객은 링크에서 3D를 돌려보고 치수를 바꿔 "수정 요청"을 보낼 수 있습니다. 수정 요청은 의뢰함에 들어오며, 전환 시 기존 프로젝트 새 리비전으로 반영됩니다.
- 확정 전 **리비전 저장**, 최종 **설계 확정**.

### ④ 2D 도면
- 조립도(+BOM, 풍선) 1장 + 가공품별 부품도 자동 생성. KS 3각법, A3, 자동 척도.
- 치수 자동 기입(외형, 구멍 위치 누적치수, n-Ø 관통 콜아웃), 재질별 주기(일반공차 KS B ISO 2768-m, 표면처리, 볼트구멍 KS B ISO 273, 용접/선반 주의사항).
- **전체 도면 ZIP** = SVG + DXF(AutoCAD/캐드 프로그램용) + BOM CSV.
- DXF는 캐드에서 열어 끼워맞춤 공차·상세 형상(탭, 키홈 등)을 추가 보완하세요.

### ⑤ 외주·발주
- 부품을 공정별(밀링/선반/제관/판금/프로파일/표면처리/구매품)로 묶고, 외주처 DB에서 **공정·재질·평점·납기**로 추천.
- **견적 요청 생성 → 메일(도면 ZIP 첨부) / 요청서 출력** → 견적 금액 입력 → 상태 "발주" → **발주서 출력** → "입고".
- 발주 합계 vs 확정 견적 비율로 마진 확인.

### ⑥ 일정
- **표준 일정 자동 생성**(설계 난이도·외주 납기 반영) → 날짜 수정·완료 체크 → 대시보드/일정 관리 간트에 통합 표시. 지연 작업은 빨간색.

## AI 도우미 사용법 (API 없이)
1. 관리자 → **AI 도우미** → 프로젝트·작업 선택 → 프롬프트 **복사**
2. **Claude 열기** 또는 **ChatGPT 열기** → 붙여넣기. 손그림/PDF는 채팅창에 **직접 첨부**
3. AI 답변 전체를 **답변 붙여넣기** 칸에 → **적용**
   - ①·② : 설계 JSON → 3D 설계에 반영 (이전 설계는 리비전으로 자동 보관)
   - ④ : 도면 변경(재질/공정/주기) → 2D 도면에 반영
   - ③·⑤·⑥ : 견적 검토 / 외주 메일 / 고객 메일 → 내용 복사해 사용, 필요시 "메모로만 저장"
4. 적용 실패 시 AI에게 "JSON 코드블록만 다시 출력해줘"

## 데이터 백업
- 관리자 데이터는 이 브라우저에만 있습니다. **설정 → 백업 파일 저장**을 주 1회.
- PC를 바꾸면 새 PC에서 **백업 복원**.
- 고객 의뢰 원본은 구글 시트·드라이브에 남아 있습니다.

## 홈페이지 수정하기 (Claude Code 구독)
- 저장소를 Claude Code로 열고 원하는 변경을 말하면 됩니다. 예)
  - "컨베이어 템플릿에 사이드 가이드 옵션 추가해줘"
  - "kb.js 의 SUS304 단가를 kg당 8000원으로 바꿔줘"
  - "새 템플릿 '스크류 피더' 추가해줘" (구조는 `CLAUDE.md` 참고)
- 변경 후 `npm test` 로 검증 → 커밋/푸시하면 GitHub Pages에 자동 반영.
