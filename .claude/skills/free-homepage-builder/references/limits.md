# 무료 한도 · 확장 경로

## 무료 한도 (변경될 수 있으니 공식 문서 확인)
| 서비스 | 주요 한도 | 영향 |
|---|---|---|
| GitHub Pages | 사이트 1GB, 월 대역폭 약 100GB(소프트 한도), 공개 저장소 기준 무료 | 이미지 최적화 필요 |
| Apps Script | 1회 실행 6분, 하루 메일 100통(일반 계정)/1,500통(Workspace), POST 본문 약 50MB | 첨부는 파일당 10~15MB 이하로 제한 |
| Google Drive | 계정 15GB 공유 | 첨부 누적 시 정리 |
| localStorage | 브라우저당 약 5~10MB | 큰 파일은 저장 금지, 주기적 백업·정리 |
| URL 공유 링크 | 실사용 약 2,000~8,000자 권장 | 큰 데이터는 시트 저장 후 ID 공유 |

## 성장 시 확장 경로 (단계적, 대부분 무료 티어 존재)
1. **관리자 데이터 공유가 필요** → store.js 저장 대상을 Apps Script(시트 탭)로 변경 (무료 유지)
2. **로그인/회원** → Firebase Auth 또는 Supabase Auth (무료 티어)
3. **DB 쿼리·실시간** → Supabase / Firebase Firestore (무료 티어)
4. **결제** → 토스페이먼츠·포트원 (수수료 기반)
5. **자동 AI 응답이 꼭 필요** → 이때만 유료 API 도입 (사용자 동의 후, 키는 서버리스 함수에만)

원칙: 확장해도 ①~② 층(정적 호스팅 + 브라우저 처리)은 그대로 유지하고, 필요한 부분만 교체한다.
